# 摺痕帶斷線修補

## 什麼時候用

`02_quality.csv` 的 `level` 是 `crease` 的區塊裡，`03_lines.csv` 的線出現斷點，
而斷點兩側的線段共線、方向一致。曬圖摺痕會把一條連續的牆線切成兩段甚至更多。

**不要**在 `good` 區用這個技能 —— 那裡的斷線通常是真的斷（開口、門洞），
硬接會製造出不存在的牆。

## 怎麼做

1. `trace(line_id)` 取得該線的接合候選。
2. 對每個候選，確認：兩段共線（夾角 < 2°）、投影不重疊、間隙落在摺痕寬度內。
3. `crop_look(bbox)` 親眼看那個斷點 —— 是摺痕造成的白帶，還是真的有開口？
4. 判定：
   - 看得出是摺痕 → 寫成 judgment，`evidence` 同時引兩段線與 `quality#<crease 區>`
   - 看不出來 → **標 `uncertain`**，`basis` 寫「依尺寸鏈補全」或「摺痕帶證據中斷」
   - 兩段接起來與尺寸鏈對不上 → 寫進 `conflicts`，不要調整幾何去遷就

## 不要做的事

- 不要因為「接起來比較整齊」就接。整齊不是證據。
- 不要用目測座標補中間那段（戒律一）。接合後的幾何仍須追溯到 chain 或 measure。
- 接了就要留痕：`overrides` 或 `note` 要寫明是摺痕修補，讓人回頭查得到。
